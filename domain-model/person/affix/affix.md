
# Affix

The "base" struct for prefixes and suffixes used with personal names.

## Programmatic Information

- ID: The [ID](../../id/id.md) of the affix
- Name:
    desc: the name of the affix 
    type: string
    validation: 
        - Min of 1 characters
        - Max of characters.
- Description:
    desc: The description of the affix
    type: string
    validation:
        - Min of 2 characters
        - Max of 500 characters
